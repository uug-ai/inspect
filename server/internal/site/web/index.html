SEE IT IN ACTION

From "that looks wrong" to a GitHub issue in twenty seconds.

Recorded in Kerberos Hub: open the toolbar, drag over the problem, annotate it, describe it, done.

WHAT YOU GET

Bug reports your developers can act on.

  • Area, element or recording

    Drag a rectangle, click an element (with its CSS selector), or record a short video while you reproduce the bug.

  • Annotate and redact

    Arrows, boxes, pen and text, plus pixelate to hide faces, number plates or personal data before anything leaves the browser.

  • Context included

    URL, browser, viewport, recent console errors and your app's own metadata. The reporter sees it all and can switch it off.

  • Straight into GitHub

    A real issue with the screenshot inline, labelled and ready for triage. Media lives on its own branch, away from your code.

  • Token stays on the server

    The browser never sees a GitHub token. The server checks the origin, file types and sizes, and rate-limits every client.

  • Any web app, one line

    No framework, no dependencies, about 14 KB gzipped. Its UI is isolated in a Shadow DOM, so it never clashes with your styles.

SET IT UP

Three steps, a few minutes.

  1. 1

    Install the library

    npm install @uug-ai/inspect
  2. 2

    Start it in your app

    import { createInspect } from '@uug-ai/inspect';

createInspect({
  endpoint: 'https://inspect.example.com',
  repo: 'your-org/your-app',
});
  3. 3

    Run the server

    One small, hardened container holds your GitHub token and files the issues. Configure it with environment variables.

    docker run -p 8080:8080 \
  -e GITHUB_TOKEN=… \
  -e INSPECT_DEFAULT_REPO=your-org/your-app \
  -e INSPECT_ALLOWED_ORIGINS=https://app.example.com \
  ghcr.io/uug-ai/inspect
